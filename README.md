# Tap Homebrew de SAASEmpiree

Installez nos apps open source, local-first, en une commande sous macOS.

## Atelier — boîte à outils de fichiers 100 % locale

```sh
brew install --cask saasempiree/tap/atelier
```

> L'app n'est pas encore signée par Apple. Au 1er lancement, si macOS bloque :
> clic droit sur Atelier → « Ouvrir » (une seule fois), ou
> `xattr -dr com.apple.quarantine /Applications/Atelier.app`.

Sous **Windows** : voir le bucket Scoop
[SAASEmpiree/scoop-bucket](https://github.com/SAASEmpiree/scoop-bucket).
