# Tap Homebrew de SAASEmpiree

Installez nos apps open source, local-first, en une commande.

## Atelier — boîte à outils de fichiers 100 % locale

```sh
brew install --cask --no-quarantine saasempiree/tap/atelier
```

`--no-quarantine` : l'app n'est pas encore signée, ce flag évite l'avertissement Gatekeeper.
Dépôt : https://github.com/SAASEmpiree/atelier-fichiers
